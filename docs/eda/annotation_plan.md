# План объёма целевой разметки

Это план подготовки данных, а не описание уже размеченного набора. В текущем снимке нет проверенных целевых меток сокрытия. Планируем разметить **200 интервалов: 100 с одним событием сокрытия и 100 с обычным действием**.

| Назначение | Сокрытие | Обычное действие | Всего | Проверка |
|---|---:|---:|---:|---|
| Примеры для подготовки инструкций и возможного обучения | 25 | 25 | 50 | Предразметка VLM и подтверждение человеком |
| Валидация | 25 | 25 | 50 | Ручной эталон, выбор настроек |
| Тест | 50 | 50 | 100 | Независимая ручная разметка без ответов VLM |
| **Итого** | **100** | **100** | **200** | |

Первые **20 интервалов (10 + 10)** входят в обучающую часть, а не добавляются сверх 200. Их сначала размечает человек без подсказок, затем сравниваем с VLM-предразметкой. Это пробный пакет для уточнения классов, границ и стоимости работы. Его результаты используются для разработки; в тест он не попадает.

Для готовой VLM обучающая часть служит источником примеров и анализа, а не означает обязательное дообучение весов. Числа 50/50 для подготовки и валидации — исходный бюджет итерации. Их достаточность проверяется после пробного пакета; при нехватке сложных случаев объём увеличивается.

## Что позволяет оценить тест по 50 примеров

Бюджет 200 интервалов позволяет получить первичную оценку recall и доли обычных интервалов хотя бы с одним ложным подтверждением. Для 50 независимых наблюдений каждого класса максимальная полуширина номинального 95%-го интервала Уилсона равна **13,36 п.п.** Это более грубая оценка, чем при тесте из 100 примеров каждого класса; меньший объём выбран для сокращения трудозатрат разметки.

Расчёт: `h_max = z / (2 × sqrt(n + z²))`, где `z = 1,95996`, `n = 50`. Это максимум по наблюдаемой доле, достигаемый при 0,5. Метод — NIST/SEMATECH e-Handbook of Statistical Methods, раздел 7.2.4.1 «Confidence intervals», интервал Уилсона.

[Скрипт расчёта](annotation_plan.py) · [Параметры и результат](annotation_plan.json).

Это ориентир планирования, а не гарантия точности. Несколько кадров или окон одного события не увеличивают число независимых наблюдений. При зависимости внутри сцен нужен больший набор или оценка неопределённости по группам. Сбалансированный тест не оценивает реальную частоту событий, точность уведомлений при естественной редкости сокрытий или ложные сигналы в час — для них потребуется отдельное обычное видео.

## Как набирать данные

- Используем имеющийся пул, но авторские классы считаем только подсказкой для отбора. Целевой класс и видимость действия подтверждает человек.
- Сохраняем группы целиком: связанные фрагменты, ракурсы и повторные копии не пересекают части. Внутри каждого класса теста берём не более одного интервала из группы; одна группа может дать положительное и обычное действие. Поэтому ориентир — минимум 50 исходных групп. Это ещё не доказательство независимости магазинов и людей.
- Включаем разные сцены и сложные обычные действия: работу с личными вещами, сумкой, одеждой и упаковкой. Не допускаем, чтобы класс определялся только источником.
- Показанные в визуальном EDA группы относятся к разработке данных и не выдаются за нетронутый тест.
- Если подходящих событий или независимых групп недостаточно, добавляем новые записи и разметку. Не набираем квоту дублями и не меняем метки под результат модели. Точные размеры частей фиксируем до итогового теста; сохранение групп важнее точного соотношения.

**Необходимая дополнительная разметка на старт — 200 интервалов.** Это не требование скачать 200 новых видео: интервалы можно взять из уже доступных источников, если они проходят ручной отбор. Объём дополнительного сбора видео определяется по фактическому выходу пригодных событий после пробного пакета.
